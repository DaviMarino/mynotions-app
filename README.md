# MyNotions — downloads

Aplicativo de cadernos para Android, com escrita à mão, texto, PDFs, pastas e uso offline.

## Instalação

Baixe o APK na seção [Releases](https://github.com/DaviMarino/mynotions-app/releases). Este repositório distribui instaladores; não contém o código-fonte do aplicativo.

- Android: versão de testes. O sistema pode solicitar autorização para instalar aplicativos dessa origem.
- Windows: instalador ainda não disponível.
- A conta é opcional para uso local; é necessária para sincronizar entre dispositivos. A sincronização envia os dados da conta ao servidor MyNotions.
- Antes de testar recursos novos com conteúdo importante, mantenha uma exportação de seus cadernos.

## Atualizações

Instale versões novas sobre a versão pública anterior, sem desinstalar, para preservar os dados. O atualizador interno ainda não está disponível. APKs antigos de desenvolvimento usam outra assinatura; não desinstale esses aplicativos sem preservar seus dados.

## Verificação

Cada release inclui SHA256SUMS.txt para conferir a integridade do APK. Problemas podem ser relatados em [Issues](https://github.com/DaviMarino/mynotions-app/issues); não inclua senhas, chaves de recuperação ou documentos pessoais.
